# Python Weather Voice App

A simple Python application that fetches real-time weather data using WeatherAPI and announces the temperature using text-to-speech.

## Features

- Get current weather for any city
- Real-time weather data using WeatherAPI
- Voice announcement using pyttsx3
- Displays temperature in Celsius

## Technologies Used

- Python
- Requests
- JSON
- pyttsx3
- WeatherAPI
